# EET-lifetime-analysis-PSI
Mapping the EET lifetimes among chromophores present in plant PSI 


## EET processes included
* chlorophyll Soret to carotenoid S2

## Data provided

* lifetimes from FRET model, and python code for analysis
* lifetimes from TDC model, with electronic structure files for the calculations

## Requirements
numpy, scipy, matplotlib, re, pandas
